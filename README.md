One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock. The program writes the line to `/output/entry.txt`: a single line, at most 200 characters, deterministic, no network, no randomness.

> I ate one sock so the pair would finally match the one the dryer took in 2019.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). The program validates the line before writing it: one line, 1–200 characters, not blank.
